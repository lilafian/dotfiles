# LilafDots v2
These are my modular dotfiles for the following:
* alacritty
* fonts
* hyprland
* nvim
* wallpapers
* zsh

Provided is a quick install script that installs any combination of the modules above, as well as a quick installer for Yay to get a system up and running.

**The install script only works for Arch Linux or a derivative (if you use pacman, your distro will work), however, the dotfiles themselves will work on any distro.**
